The local dashboard uses licensed Aptos fonts from the owner's Microsoft Office installation.
Font binaries are ignored by Git. For another installation or deployment, supply your licensed
font files here as `Aptos-Regular.ttf`, `Aptos-Bold.ttf`, `AptosDisplay-Regular.ttf`, and
`AptosDisplay-Bold.ttf`. Without these files the theme falls back to Calibri or the system sans serif.
