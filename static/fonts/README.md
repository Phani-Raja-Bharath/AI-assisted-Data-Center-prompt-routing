The dashboard serves `Aptos-Regular.ttf` and `Aptos-Bold.ttf` from this directory
through Streamlit's static route. Include both files in every deployment so users
receive Aptos even when it is absent from their device. The theme uses the same
Aptos family for body text, headings, tables, and charts.

These files come from the owner's licensed Microsoft Office installation.
Deployment owners are responsible for the applicable font hosting rights.
The unused Aptos Display variants remain ignored by Git.
